# 共享页面加入个人空间：实现与验证

2026-11-06，基线 `61eef78`，开发分支 `feat/shared-page-space`。

## 实现

- 分享页顶部保留原权限标签，新增登录后加入、加入中、已加入和在我的空间打开状态。
- 复用原 OAuth 登录，保存并验证本地回跳路径；Google 常规回调、微信跨域登录中转均传递原地址。登录后由用户执行加入。
- store 新增 `addSharedPage` / `removeSharedPage`，成功后使用后端完整列表更新。不会将后续摘要刷新失败误报成加入失败；未缓存的服务器入口也保留位置。
- 空间 `/my?page_id=<分享ID>` 定位对应页面，复用现有展示、编辑和自动保存；自己分享跳转到服务器返回的 owner ID。
- 桌面与移动列表展示“共享 · 可编辑 / 共享 · 只读”，非本人共享入口提供移除；可移除最后一个入口并显示空空间。
- 权限取自后端 `page_conf`。失效摘要或详情/保存的 404、410 会清空入口缓存内容和权限，显示“分享已失效”；迟到的读取、保存或转移响应不能恢复失效缓存。
- 加入、切页、路由跳转和移除复用未保存保护。已确认失效的共享页若有无法写回的自动保存快照，先在当前浏览器标签页保留完整草稿，再允许继续；顶部可下载未保存内容，移除后仍可下载。普通网络失败仍阻止离开。存储失败保留原保存队列。
- 成员写入串行化；排序在调用时捕获原列表，通过 `base_page_ids` / `check_base` 防止旧排序覆盖新成员或复活已移除入口。
- 退出登录或切换账号时清理空间状态。

## 自动化验证

`npm test` 与 `npm run build` 通过。测试覆盖失败保留状态、重复与并发操作、未知摘要、空列表、退出登录、失效清理、迟到读写、旧排序基线、草稿保留失败和登录回跳校验。

浏览器均使用本机 Vite 和模拟 API，不修改真实账号数据：

| 脚本 | 通过的场景 |
| --- | --- |
| `tests/browser/shared-space.js` | 8 组：桌面加入失败/重试/加载/排序；从空间编辑原共享内容和重新加载；R/E 分别关联、只读不升级；移除失败与再次加入；撤销占位及其他页面；390px 移动端加入状态/打开/移除/空空间；本人页面跳回；访客 OAuth 登录回跳 |
| `tests/browser/shared-space-races.js` | 3 组：初始摘要失败后重试；加载中移除与迟到响应；真实拖拽触发撤销后的保存失败，完整草稿可下载且允许访问其他页面 |
| `tests/browser/add-link-entry.js` | 原有 11 项：`/my`、`/page/fixture`、`/share/fixture` 的加号、单条/批量/导入及可用页面的全局添加入口 |
| `tests/browser/link-drag.js` | 原有 14 项：空间和详情页的跨合集拖拽、边缘/标题落点、空合集、排序及取消 |

运行示例：

```sh
npm run dev -- --host 127.0.0.1
playwright-cli --session forgeturl-shared open http://127.0.0.1:3000
playwright-cli --session forgeturl-shared run-code --filename tests/browser/shared-space.js
```

生产构建存在依赖自带的 Browserslist 数据陈旧提示，不影响构建。
